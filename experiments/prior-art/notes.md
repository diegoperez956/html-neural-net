## Verified primary sources (captured in raw/)

### CSS Turing completeness
1. `raw/lemire2011.html` — Daniel Lemire, "Breaking news: HTML+CSS is Turing complete",
   2011-03-08 (via Wayback snapshot 2025-12-28). Claim: HTML5+CSS3 Turing complete via
   Rule 110 (pointer from Jakob Voß). Comment thread: Sylvain Hallé notes reliance on
   `:nth-of-type(an+b)`; "Mr Speaker" notes reliance on human interaction every tick.
2. `raw/so5357725.html` (403'd direct; facts from StackExchange API) — SO Q 5357725,
   2011-03-18: "How does this implementation of turing-complete Rule 110 in HTML5+CSS3
   work?" links `http://elilies.com/rule110-full.html` ("press tab and space in sequence
   to run the automaton"). Accepted answer: "Each of the grid boxes is really a checkbox.
   Hitting space with it selected toggles its state." — i.e., :focus + :checked + human clock.
3. `raw/elilies-rule110.html` — elilies.com now redirects to eli.fox-epste.in (personal
   site); demo dead. Wayback CDX has 2011-03-11 capture but archive.org currently serves
   "Temporarily Offline" placeholder (raw/elilies-rule110-wb.html). Demo content NOT
   retrievable today; existence+mechanism verified via SO question only.
4. `raw/accodeing-2015.html` — accodeing.com 2015 "CSS3 proven to be Turing complete":
   attributes original Rule 110 CSS/HTML demo to "Eli & Jonas, early 2011" presented at a
   Hack && Tell; argues a modified version is "more Turing complete than C" under a
   streaming-HTML model.
5. `raw/notlaura-css-turing.html` — Lara (Schenck) Karki, "Is CSS Turing Complete?",
   notlaura.com, 2019-05-25. Thesis: "CSS + HTML + user input is Turing complete."
6. `raw/cherlin-css-is-turing-complete.html` — Clement Cherlin, "CSS is Turing Complete",
   mooninaut.github.io/css-is-turing-complete/, Oct 2022 (repo Mooninaut/css-is-turing-complete,
   created 2022-10-03, 25 stars, CC BY-SA 4.0). :has()-based 2-state 2-symbol Busy Beaver
   Turing machine; also a Boolean-circuit evaluator with a full adder (2 XOR, 2 AND, 1 OR),
   inputs hard-coded to 1+1+1; bits transition via non-repeating animations; "no JavaScript,
   images, SVG"; mouse hover to start, then autonomous (no human per-tick).
7. `raw/janeori-cpu-hack.html` — Jane Ori, "Expert CSS: The CPU Hack", dev.to, 2023-09-17.
   Animation-as-clock technique: registered (@property) integer custom property + keyframe
   caching to tick continuously without JS; demos: integer compute, mouse-coordinate zoom,
   Conway's Game of Life 42x42, Breakout. Chrome-only quirks documented.
8. `raw/lyra-x86css.html` — Lyra Rebane, "x86CSS — x86 CPU made in CSS", lyra.horse/x86css,
   surfaced ~Feb 2026 (kottke 2026/02, CSS Weekly, i-programmer, Tom's Hardware). Full 8086
   CPU: ADD/ADC/SUB/SBB/AND/OR/XOR/CMP, shifts, jumps, MOV, PUSH/POP, MUL/DIV etc., 1.5kB
   RAM, custom I/O, runs GCC-compiled C programs (gcc-ia16). CSS-only (script tag only as
   optional clock; JS-less animation+style-container-query clock exists). Chromium-only:
   uses if(), style queries, custom @functions. Base CSS handwritten; repetitive parts
   generated by Python build script. Credits Jane Ori's CPU Hack.
9. `raw/gizmosmith-2012.html` — Gizmosmith blog, 2012-08-15: speculation only (selectors
   = AND, :not = NOT ⇒ NAND universality), no implementation, explicitly doubts whether
   outputs can feed inputs.

### Gates / adders / calculators
10. `raw/silon.html` + Silon README (silon.slaks.net; github.com/SLaks/Silon, created
    2015-04-08, 342 stars) — Schabse Laks, "Silon: Adders & Logic Gates in Pure CSS".
    AND/OR/XOR gates, half adder, full adder, chained 4-bit adder (two 4-bit inputs 0-15 →
    5-bit sum), plus a decimal adder. Mechanism: LESS DSL `.op(a, and|or|xor, b, result)`
    expands boolean expressions to truth tables encoded as CSS selectors (sibling `~` = AND,
    `,` = OR, `:not()` + `:checked`). Runtime = pure CSS selectors; "no Javascript anywhere"
    (JS only in Gulp build + GA). Secondary: css-tricks.com/adders-and-logic-gates-in-pure-css/
    (Chris Coyier, 2015-06-08).
11. `raw/amit-conffab-transcript.html` — Amit Sheen, "Building a Computer with CSS",
    CSS Day 2025 (talk transcript on conffab.com). Checkbox inputs; 7 gates via attribute
    selectors `[data-type="not"]:has(input:checked)` etc. setting output custom property
    `--on`; half adder; full adder (code shown: `--on: calc(mod(var(--and1,0) + var(--xor2,0), 2))`,
    `:has([data-digit="2"]:checked ~ [data-digit="2"]:checked) { --and2: 1 }`,
    `--and3: calc(var(--and1,0) * var(--xor2)); --on: calc(var(--and2,0) + var(--and3,0))`);
    5-digit adder/subtractor; binary→decimal via `counter-increment: total calc(pow(2, var(--i)))`.
    "No JavaScript, no magic." Pens (raw/amit-pen0*.css, published 2025-06-03; link page
    via Wayback 2025-07-11): PwqzjVr gates, emNzEjj half adder, QwbEMRa full adder,
    yyNJoWE five digits, bGJvopM binary-to-decimal. Bare pen URLs now 404; revision URLs work.
12. `raw/janeori-space-toggle-demo.html` — Jane Ori, "CSS 'Space Toggle' State Machine /
    Logic Demo" (propjockey.github.io/bcd7sdd, Apr 2020; space-toggle previously found by
    Ana Tudor ~2017): BCD→7-segment decoder as real binary logic in vanilla CSS, no JS;
    checkboxes as input source.
13. CodePen `Oka/azzPdW` "CSS3 Logic Gates using Checkboxes" — exists (title verified via
    jina); minor, no deep docs; not inspected in detail.

### CSS neural networks / inference
14. `raw/graham-pure-css-nn.html` — GrahamTheDev (Graham), "Pure CSS Neural Network"
    dev.to/grahamthedev/pure-css-neural-network-aiits-easier-that-you-think-f02,
    published 2023-10-30. THE found CSS inference demo: pre-trained weights as :root custom
    properties; 2 inputs (radio-button coordinate grid) → 4 outputs (quadrant classifier).
    Forward pass in calc(): dot products `--output1a: calc(var(--weights1-1)*var(--inputX)
    + var(--weights2-1)*var(--inputY))`; ReLU `max(0, out) + bias`; argmax via
    `max(...)` + squared-difference×1e9 trick → one-hot; outputs rendered with CSS counters
    (integer hack ×1e5). Author: sigmoid impossible (exp() browser support), training
    "next to impossible" in CSS (calc chain limits), single layer 2→4, NO hidden layer,
    NO XOR/MLP. Follow-up OCR article never found. Pen JjwqNJV (title "neural network in css").

### Checkbox hacks / custom-property computation
16. `raw/csstricks-checkbox-hack.html` — Chris Coyier, "The Checkbox Hack", css-tricks.com,
    Nov 2011 (per comments; page lists tabs/dropdowns/toggles/FAQ patterns; credits Ryan
    Seddon for custom radio/checkbox pioneering).
17. MDN `@property` and `calc()` pages — both HTTP 200 (2026-08-30). Registered custom
    properties: syntax/inherits/initial-value; animation/interpolation of registered props.
18. lab.avl.la/css-calculations (github MatheusAvellar/css-calculations, created
    2021-01-05) — Fibonacci + two PI series (Nilakantha, Leibniz) computed in pure CSS:
    custom properties + calc() + element nesting (inheritance carries values across
    iterations). FAQ: "No JavaScript ... is being used to calculate the values. JavaScript
    is being used on the buttons to 'request' another iteration ... simply adds an empty
    element ... Everything will continue to work if you disable JavaScript." Firefox-only.
19. Counter-as-output trick (Graham, #14): `counter-reset: x var(--y)` + `content: counter(x)`
    to render computed values; getComputedStyle returns the calc() string, not the value.
